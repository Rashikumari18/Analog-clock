# Analog Clock 🕐

A simple and interactive analog clock built using HTML, CSS, and JavaScript. The clock displays the current time in real time with smoothly moving hour, minute, and second hands.

## Features

- 🕐 Real-time clock
- ⏱️ Moving hour, minute, and second hands
- 🔄 Automatically updates with the current time
- 🎨 Clean and simple interface
- 📱 Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How It Works

JavaScript is used to get the current system time and calculate the rotation of the hour, minute, and second hands. CSS is used to design the clock face and position the hands.

## What I Learned

Through this project, I practiced:

- JavaScript Date object
- DOM manipulation
- CSS positioning and transformations
- JavaScript timing functions
- Creating real-time interactive web elements

## How to Run

1. Clone or download this repository.
2. Open the `index.html` file in your browser.
3. The clock will automatically display the current time.
